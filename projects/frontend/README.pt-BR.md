# Projetos de Desenvolvimento Frontend

Construa interfaces que as pessoas gostam de usar: layouts responsivos, UIs em
tempo real, componentes acessíveis e SPAs performáticas. São exercícios
guiados — você recebe o *o quê* e o *porquê*, e então escreve o código.

> Cada projeto tem um brief em inglês (`README.md`) e outro em português
> (`README.pt-BR.md`).

## O Que Você Vai Construir

- Apps interativos com estrutura limpa baseada em componentes
- Interfaces em tempo real com WebSockets
- Design systems e bibliotecas de componentes reutilizáveis
- PWAs offline-first e dashboards otimizados para desempenho
- UIs acessíveis que atendem aos padrões WCAG

## O Que Você Vai Aprender

- **Fundamentos web**: HTML semântico, CSS moderno, JavaScript ES6+
- **Frameworks**: modelos de componentes em React, Vue, Angular ou Svelte
- **Estado**: gestão de estado local, global e do servidor
- **Desempenho**: code splitting, lazy loading, virtualização
- **Acessibilidade**: ARIA, navegação por teclado, leitores de tela

## Trilha de Aprendizado

- **Iniciante (2–4 semanas)**: HTML, CSS, JavaScript puro, eventos do DOM,
  design responsivo.
- **Intermediário (4–8 semanas)**: um framework moderno, arquitetura de
  componentes, gestão de estado, integração com APIs.
- **Avançado (2–3 meses)**: apps escaláveis, otimização de desempenho, padrões
  avançados, acessibilidade e testes.

Construa responsivo e acessível desde o primeiro dia — não deixe para depois.

## Conceitos-Chave

1. **Tecnologias base** — HTML5, CSS3, JavaScript ES6+
2. **Design responsivo** — mobile-first, flexbox, grid
3. **Componentes** — elementos de UI reutilizáveis e componíveis
4. **Gestão de estado** — local vs. global vs. do servidor
5. **Dados** — fetch, HTTP, WebSockets
6. **Desempenho** — code splitting, lazy loading
7. **Acessibilidade** — ARIA, teclado, leitores de tela
