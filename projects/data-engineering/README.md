# Data Engineering Projects

Build the infrastructure that moves, transforms, and stores data reliably at
scale: ETL/ELT pipelines, streaming, warehouses, and data lakes. These are
guided exercises — you get the *what* and the *why*, then you write the code.

> Every project has both an English (`README.md`) and a Portuguese
> (`README.pt-BR.md`) brief.

## What You'll Build

- Batch ETL pipelines and file ingestion systems
- Orchestrated workflows with schedulers like Airflow
- Streaming pipelines with Kafka and real-time processing
- Data warehouses, data lakes, and CDC pipelines
- Distributed, cost-optimized, self-healing infrastructure

## What You'll Learn

- **ETL/ELT**: extract, transform, load patterns
- **Orchestration**: DAGs, scheduling, dependencies
- **Streaming**: pub/sub, windowing, exactly-once semantics
- **Modeling**: dimensional modeling, schema evolution
- **Reliability**: idempotency, retries, monitoring, data quality

## Learning Path

- **Beginner (3–4 weeks)**: SQL fundamentals, ETL concepts, simple pipelines
  and loaders, CSV/JSON handling.
- **Intermediate (6–8 weeks)**: orchestration with Airflow, warehousing,
  Kafka streaming, monitoring and validation.
- **Advanced (2–3 months)**: distributed systems, scalable architectures, data
  mesh and CDC, cost and performance optimization.

Design for reliability and observability from the first pipeline.

## Key Concepts

1. **SQL** — queries, indexing, transactions
2. **ETL design** — extract, transform, load patterns
3. **Data modeling** — schema and dimensional modeling
4. **Scalability** — partitioning, sharding, distribution
5. **Reliability** — error handling, retries, idempotency
6. **Monitoring** — alerting, logging, metrics
7. **Data quality** — validation, reconciliation, governance
